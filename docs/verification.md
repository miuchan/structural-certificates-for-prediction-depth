The project pins Lean `v4.36.0-rc2` and the dependency versions. Run the following command from the repository root. [Pinned dependencies](dependencies.md)

```sh
./scripts/check.sh
```

The script checks default entry-point coverage, runs `lake build --wfail`, audits transitive axiom dependencies of project declarations, and runs a negative regression test.

```text
Entry point covers all 96 project modules.
Build completed successfully (4972 jobs).
Audited 3282 project declarations: only propext, Classical.choice, Quot.sound.
Audit regression passed: AuditRegressionExternal.unexpectedTheorem transitively depends on unapproved axiom AuditRegressionDependency.unexpectedOracle.
```

Build jobs include dependencies. The declaration count includes definitions, theorems, and auxiliary declarations generated by Lean.

The audit selects declarations by their defining module. `scripts/check_audit.py` compiles a project theorem in a temporary directory. The theorem is in a different namespace and depends on an external axiom through an intermediate theorem. The regression test requires the production audit to exit with a nonzero status and identify the expected theorem and axiom.

The GitHub Actions workflow runs the same script on Ubuntu. Push events check the pushed commit. Pull request events check the merge commit generated by GitHub. The workflow checks that the checked-out SHA matches the event SHA and writes the verified SHA to the run summary on success. Find the corresponding public run with `gh run list --commit <SHA>`. [GitHub Actions workflow](../.github/workflows/lean.yml)

## Mathematical verification

- A has Lean proofs for the finite circuit construction, path-local conditions, arbitrary global state spaces, the uniform generator, and NC membership under the cost conditions. The uniform compiler accounts for copy gates during normalization. A binary time encoding alone does not give the required depth bound in input length.
- The standard B instance uses concrete machines and proved CVP completeness. The project proves uniform NC closure under general variable-length logspace reductions. The conditional result retains the explicit `P ≠ NC` assumption.
- C proves the integer bound `m ≤ b^d`, its logarithmic form, and finite witnesses using distinguishing assignments. The proof covers circuits with sharing.
- The OR example includes proved state semantics, a finite encoding, a concrete uniform generator, a fixed polynomial budget, exact optimal depth, and a matching lower bound for all shared De Morgan circuits. It covers time zero.
- The binary-field matrix example uses concrete XOR and AND circuits and gives depth, gate count, and complete description-size bounds. The propagation lower bound imposes locality on the predictor itself.
- The frozen-control family includes the coefficient formula for arbitrary initial controls, path compilation and decoding, logarithmic-depth upper bounds, a logspace-uniform generator, and a matching lower bound for the AND/OR example. [Frozen-control rules](frozen-pascal.md)
- The frozen-control classification characterizes when a single constant bounds all times. Varying guards have a logarithmic fan-in-two lower bound. The per-time homogeneous Pascal bounds depend on the number of set bits in the time. The constant-depth and Pascal circuits have explicit gate bounds.
- The executable classifier agrees with the four semantic conditions. The uniform theorem gives language correctness, polynomial size, and regime-specific depth for the same generated family, and characterizes membership in standard uniform NC⁰.
- The transported-control model derives the finite-window conjunction from synchronous evolution on the infinite lattice, identifies the essential inputs exactly, and attains optimal depth with a linear-size construction. The lower bound covers binary networks with sharing. This is a per-time circuit result. [Lean theorems](../PredictionDepth/TransportedControl.lean)

An independent review also checked work-space accounting, append-only output, finite control, variable output length, canonical time encodings, the distinction between path and global conditions, and whether a single family witnesses uniformity, size, and depth.
