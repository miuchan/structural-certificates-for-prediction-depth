# 冻结控制的一侧元胞自动机

取固定的有限控制字母表 $`A=\{0,1\}^q`$，以及两个固定的布尔函数 `stay` 和 `hop`。格点 $`i`$ 的状态由控制字 $`a_i`$ 和数据位 $`x_i\in\mathbb F_2`$ 组成。每一步同步更新为

```math
a_i'=a_i,\qquad
x_i'=\operatorname{stay}(a_i)x_i+\operatorname{hop}(a_i)x_{i+1}.
```

加法和乘法在 $`\mathbb F_2`$ 上进行。控制字是初始输入的一部分，可以逐格独立变化。规则在所有格点相同。若 $`\operatorname{stay}`$ 非常值，则自身数据位的系数取决于控制字，因此联合规则非仿射。一个例子取两位控制字，分别用 AND 和 OR 作两个控制函数。冻结的是控制轨，数据轨可以振荡。

## 预测上界

预测原点数据位只需格点 $`0,\ldots,T`$ 的初值。设 $`s_k`$ 是区间 $`[0,k]`$ 内允许原地等待的格点数，$`e_k`$ 是前 $`k`$ 条边的通行标志之积。Lean 中的 `iterate_data` 证明

```math
x_0(T)=\sum_{k=0}^T e_k\,\operatorname{multichoose}(s_k,T-k)\,x_k(0)
\pmod 2.
```

一个贡献来自初始位置 $`k`$ 的路径必须经过恰好 $`k`$ 条边。其余 $`T-k`$ 步是停留，可分配到这条路径上允许等待的格点。路径上的格点次序固定，因此停留分配与弱组合一一对应。若 $`s_k=0`$，只有 $`T=k`$ 时系数为 1。若 $`s_k>0`$，系数为 $`\binom{s_k+T-k-1}{T-k}`$ 的奇偶性。

电路并行计算每个前缀的计数和通行标志，再用平衡异或归约。查表系数的生成只需检查二进制位之间的蕴含关系，`directTableBit_eq` 给出了 Lucas 定理形式的正确性证明。四个寄存器块分别存放单热时间标签、两个控制标志和数据位。初始化、平方和乘以种子分别准备标签 0、将标签位置倍增、将标签位置加一。预测时刻的标签选择正确的系数。实际电路经框架的 `RegisterWitness` 编译，逐时刻的显式上界为 $`7+33\lceil\log_2(T+2)\rceil`$ 层和 $`113(T+2)^4`$ 个门。把控制函数作为固定的局部布尔电路并行求值，仅再增加两者深度的最大值。

`no_global_decoder` 说明该时间标签确实有路径局部性。对任意正时间窗口，所有超出窗口的标签都变成全零，但同一个有限初始输入在两个相邻的超时时刻可给出不同答案。这个结论约束的是这里选用的编码。

`guarded_prediction_depth_lower_bound` 给出一个与规则结构直接相关的下界条件。若能选择两个控制字，使它们都允许传输，但分别开启和关闭等待，就可以让所有边通行，同时只允许在原点等待。预测于是变成全部 $`T+1`$ 个数据位的奇偶校验。任意二输入门电路的深度至少为 $`\lceil\log_2(T+1)\rceil`$。AND/OR 控制的规则可以选择 $`(1,1)`$ 和 $`(1,0)`$，因此其最优预测深度为 $`\Theta(\log T)`$。

## 对数空间统一性

`UniformWeight.basis` 用逐层进位保存加法计算前缀计数。层数和进位清理轮数都由计数位宽决定。Lean 证明这些层的接线及其拼接可由对数空间转导器生成，查表系数和时间标签也有独立的生成器证明。

统一构造沿用同一时间标签和路径语义，深度至多为 $`104(\lceil\log_2(T+3)\rceil+1)+\max(d_{\rm stay},d_{\rm hop})`$。上一节的显式门数界针对逐时刻构造。统一族的多项式规模由生成器的输出长度界推出。

`predictionLanguage_mem_uniformNC_one` 对任意固定控制字宽和固定控制函数证明标准对数空间统一 NC¹。对长度为 $`n=(q+1)(T+1)`$ 的合法输入，电路从长度得到时间 $`T`$，并精确预测原点；空串和无法组成整格的长度被拒绝。

## 文献对照

Moore 1998 年论文的 Lemma 1 和 Theorem 1 涵盖系数在空间和时间都可变化的拟直积演化。本文的冻结控制是其中的特例。该论文用时间区间分治求各个传递系数，对二输入门得到通用 $`O(\log^2 T)`$ 上界。本例专门利用时间不变性和单向传播，用前缀计数直接求系数，得到 $`O(\log T)`$ 上界。 [Moore 论文](https://arxiv.org/abs/patt-sol/9701008)

双对角矩阵函数的经典公式可用超对角线乘积和对角元素的差商表示。对幂函数使用完整齐次对称多项式，并将对角元素取为 0 或 1，会得到这里的多重组合系数。本文用有限域上的路径计数证明这一特化，避免在特征 2 中使用阶乘的逆元。贡献集中在这一规则族的深度改进、实际统一电路构造和路径见证。现有文献检索没有找到直接陈述同一规则族的同一统一上界，优先权仍需更广泛的文献核对。 [Higham，定理 6.1](https://doi.org/10.13001/ela.2024.8297)
